# Frontend (web)

Ovdje smještate web korisnički interfejs aplikacije.  
Možete koristiti React, Angular, Vue ili jednostavni HTML/CSS/JS.

Korisni alati:  
- Figma za dizajn interfejsa: https://www.figma.com/  
- Color Hunt (palete boja): https://colorhunt.co/

# Frontend (mobile)

Ovdje smještate mobilnu aplikaciju (Android, iOS ili cross-platform rješenja kao što su Flutter ili React Native).  
Dodajte uputstvo za instalaciju i pokretanje.

Korisni alati:  
- Flutter dokumentacija: https://docs.flutter.dev/  
- Android Developers: https://developer.android.com/
- UI inspiracija: https://dribbble.com/
